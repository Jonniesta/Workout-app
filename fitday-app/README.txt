FITDAY — ANDROID BODYWEIGHT EDITION

Based on the uploaded Jonny 12 Month Plan.xlsx. This app uses an equipment-free 12-week adaptation with 4 strength days, 2 light-activity days, and 1 recovery day. The Excel workbook includes 12 weeks of sessions, not a complete 12-month schedule.

INSTALL ON ANDROID (CHROME):
1. Extract this ZIP on a computer.
2. Upload the contents of the fitday-app folder to a public HTTPS site such as GitHub Pages or Netlify. Publish the folder root (index.html, manifest.webmanifest, sw.js, icons).
3. Open the live HTTPS site in Chrome on your Android phone.
4. Tap the three-dot menu > Add to Home screen > Install (wording can vary).
5. Open FitDay from the phone home screen.

IMPORTANT: Opening the index.html file from a downloaded ZIP or through file:// does not install a PWA. A live HTTPS URL is required. Data are stored in this phone/browser; use Export backup before clearing data or changing phones.

TRAINING: Week 1–4 foundation, 5–8 build, 9–11 challenge, week 12 deload. Choose your cycle start date inside Train. Logs are kept on the device. Some gym pulling movements cannot be reproduced at equal resistance without equipment.
